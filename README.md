# ADSO (DOTACIONES FORTUNA IJ)
Este repositorio ha sido creado con el propósito de gestionar el versionamiento y control de cambios del proyecto Dotaciones Fortuna IJ, desarrollado como parte del proceso de formación en el Servicio Nacional de Aprendizaje (SENA).

Aquí se almacenan de manera organizada los archivos, documentos, códigos fuente y actualizaciones del proyecto, permitiendo un trabajo colaborativo, seguro y eficiente. El uso de GitHub facilita el seguimiento de cada modificación realizada, el respaldo de la información y la implementación de buenas prácticas de desarrollo de software.

Proyecto: Dotaciones Fortuna IJ
Objetivo: Diseñar y desarrollar una solución tecnológica para optimizar los procesos de la empresa Dotaciones Fortuna IJ, aplicando metodologías de desarrollo, control de versiones y trabajo colaborativo.

Este repositorio evidencia el proceso de aprendizaje, la evolución del proyecto y el cumplimiento de los requerimientos académicos establecidos por el SENA.
